# Overview
The application is currently in its ideation phase. While I have a working prototype thanks to Claude, after discussing with different folks, they have given me a few suggestions. Plus, there are a few modifications that I personally would like to make after using it.

## New Features
* A new user should have the option to add different muscle groups -- for example, chest, back, triceps, quads, glutes, calves, shoulders, lats, etc. Doing this would allow a user to couple exercises and have more detailed insights of progression specific to a targetted muscle. Alternatively, the user can just begin to input exercises as they like.
* Potentially add a subscription option where the user receives a weekly summary higlighting total reps, number of times they worked out, and possibly a comparision to performance a prior week.
* Once closer to launch, I would like an updated csv to be emailed to the user (again, this would be optional). I do not want to store the data in a cloud because then I would have to look into securing storing the data. I rather have a the user input what they feel comfortable inputting and have only them have access to it. 
* Ability to edit exercise names
* For bodyweight exercises, such as pull ups and dips, they can often be a combination of nonweight and weighted. To distinguish the two, perhaphs I can do just the number of reps for non-weighted and for weighted reps x weight.

## Minor Updates
* Change failure set symbol (currently X) to a more distinguishable symbol. 
* Make the prefilled weight to highest weight of the previous time you did that workout. Or maybe just display that information somewhere on the screen and don't add it
